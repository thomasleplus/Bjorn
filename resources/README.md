# resources

Static assets for the e-Paper display and app UI.

- `waveshare_epd/` — the Waveshare 2.13" e-Paper HAT driver library (vendored;
  used by [`../epd_helper.py`](../epd_helper.py) / [`../display.py`](../display.py)).
- `fonts/` — fonts rendered on the display.
- `images/` — display artwork and status icons.
- `comments/` — text snippets shown by the "Tamagotchi"-style status messages.
