# web

The web interface served by [`../webapp.py`](../webapp.py) — used to monitor and
control Bjorn from a browser (in addition to the e-Paper display).

- `bjorn.html`, `config.html`, `credentials.html` — the main pages (dashboard,
  configuration, captured credentials).
- `css/` — stylesheet(s).
- `images/` — UI art and PWA icons (`icon-*x*.png`, `favicon.ico`, …).
